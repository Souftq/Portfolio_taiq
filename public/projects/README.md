# Captures d'écran des projets

Dépose ici les images de tes projets, puis référence-les dans
`src/data/projects.js` via le champ `images`.

## BiblioGest (déjà attendu par le code)
Renomme tes 5 captures exactement ainsi et place-les dans ce dossier :

- `bibliogest-1-accueil.png`      → page d'accueil (« Bienvenue dans notre bibliothèque »)
- `bibliogest-2-bibliotheque.png` → section Bibliothèque / catalogue
- `bibliogest-3-faq.png`          → section FAQs
- `bibliogest-4-contact.png`      → section Contact (carte du monde)
- `bibliogest-5-connexion.png`    → écran de connexion Clerk

## Autres projets
Ajoute tes captures (ex: `oculus-1.png`, `tower-defense-1.png`) puis liste-les
dans le champ `images` du projet correspondant.

> Astuce : le `.png` ou `.jpg` fonctionnent. La 1re image de la liste sert de
> couverture, et un clic ouvre la galerie plein écran.
